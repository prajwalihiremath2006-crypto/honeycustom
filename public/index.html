Reports

Live database totals and CSV batch export.

Important: this version implements a hash-linked database history, not a deployed decentralized blockchain or Solidity smart contract. A real blockchain/test-network integration requires a contract, network configuration, wallet/test funds and transaction handling. Hash verification also cannot prove physical honey purity; trustworthy inspection or laboratory testing is still needed.

Contact / Help & security

Project guidance and current security boundaries.

How to use

  1. Create a customer or beekeeper account.
  2. Beekeepers can add apiaries, hives and harvest batches.
  3. Authorized processing users can attach quality reports and record supply-chain events.
  4. Generate QR from a batch card; scan it to open the public tracking page.
  5. Verify the stored record hash and previous-record link.
  6. Export the batch CSV report.
Security: password hashes are stored with bcrypt; sessions use HttpOnly cookies; forms are validated; uploaded files are limited to PDF/JPG/PNG/WEBP and 5 MB; write endpoints have a basic in-memory rate limit. Before public deployment, set a strong SESSION_SECRET, enable HTTPS, use a persistent production session store, add CSRF protection, backups, and review access control. Do not publish this prototype with the default session secret.
